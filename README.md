# Portfolio Website

A modern, responsive portfolio website showcasing my skills and projects.

## Features

- 🎨 Modern gradient design with purple/pink accents
- 📱 Fully responsive layout
- 🌓 Dark/Light theme support
- ⚡ Smooth scroll navigation
- 💫 Animated skill bars
- ✨ Typing animation on hero section
- 📧 Contact form with validation
- 🎭 Scroll-reveal animations

## Sections

- **Home**: Hero section with animated text
- **About**: Brief introduction
- **Skills**: Animated progress bars showing technical skills
- **Projects**: Showcase of completed projects
- **Contact**: Contact form

## Technologies

- HTML5
- CSS3 (with custom properties, gradients, animations)
- Vanilla JavaScript

## Customization

To personalize this portfolio for your own use:

1. Update the name and content in `index.html`
2. Modify the skills in the Skills section
3. Add your own projects to the Projects section
4. Update the typing animation phrases in the JavaScript
5. Customize colors in CSS custom properties
